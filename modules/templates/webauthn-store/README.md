Wires `passkeys`' stores. Its credential records are `records`' records in `webauthn-store.credentials`, kept without end; its part of each subject's flow (`passkeyPart`: the keys and the reservation) is bound to `webauthn-store.keys` through `transparency-frames`' `frameParts`, so the frame store writes it in a flow's one write. Both spaces are `retained`, as the log keeps each key's flow, and need no subject writer, as a Step's one write carries none. The credentials' space declares a guarantee for each need `passkeys` states, and the keys' space one for each need `transparency` states for its frames (never evicted, durable, replicated, confirmed reads, authenticated), which the frame store refuses any part's space to lack; a need with nothing mapped to it fails the type check. On a store that does not tell a write made outside the provider apart, both boot only under store's `accept-unauthenticated`. The wiring only maps, with no branches or loops. Depends on `kernel`, `passkeys`, `records`, `store`, `transparency` and `transparency-frames`.

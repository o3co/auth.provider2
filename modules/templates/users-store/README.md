# users-store

Wires `users`' store interface to `subject-records`' records, kept without end, over the phase this process reads once: verified contacts in `users-store.contacts` (`online-keyed`, keyed by the subject itself), erased by `users` and declared beside its index space. The contact store offers its `erase` and `migrate` as a whole set, straight from the builder. The space declares a guarantee for each need `users` states for it. A need with nothing mapped to it fails the type check, and `users`' store contract, run on a store that loses what a missing guarantee allows, in both phases, checks what each guarantee means. The composition is out of traffic while the phase cannot be read (probe `users-store.phase`). The wiring only maps, with no branches or loops. Depends on `kernel`, `users`, `subject-records` and `store`.
